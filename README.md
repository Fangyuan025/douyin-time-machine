# 时光机 · 抖音第三方 macOS 客户端

按**发布时间**刷抖音：选择任意年份/月份（精确到月，支持跨月、跨年区间），时光机会为你生成一条只包含该时间段视频的 FYP 式视频流。

## 构建与运行

需要 macOS 14+、Xcode 15+（Swift 5.10+）。

```bash
./scripts/build_app.sh          # 生成 build/时光机.app（release）
open build/时光机.app
```

开发时也可以直接用 Xcode 打开 `Package.swift`，或 `swift run`。

自检（不打开界面，验证数据链路是否正常）：

```bash
build/时光机.app/Contents/MacOS/TimeMachine --selftest
```

## 功能

- **扫码登录**：内嵌抖音官方网页，用抖音 App 扫码；登录态持久保存，可随时退出。
- **时间筛选**：月份网格（点月份选起点；同一个月再点一次 = 只看这个月并出发；点另一个月 = 区间并出发）、整年、快速穿越预设、随机穿越。
- **两种范围**：「全站探索」，或「只看我关注的」——看看你关注的人在那段时间发了什么。
- **智能视频流**：原生 AVPlayer 播放，上下滑动/滚轮/方向键切换；双播放器轮换做真正的预缓冲，720p 优先起播；播放地址失效自动刷新。
- **时代感**：内置 2016–2026 年按月整理的时代热点时间线（含疫情三年的核酸、大白、方舱、阳了等），优先翻当时的热门话题页；标题或话题命中当月热点的视频会被优先推荐并标注「当时的热点：xx」。
- **还原当时的推荐页**：每一条按推荐页配比轮换——当时的热点（约 35%）、当时的热门（约 30%）、可能感兴趣的普通人日常（约 35%，舞蹈、vlog、萌宠、带娃……）；同一个热点词 10 条内最多 2 次，不会刷屏。
- **每次刷新都不一样**：最近几天出现过的作者自动降权，最近 7 天展示过的视频不再推荐；排序、挑创作者、同一作者选哪几条作品都带随机性。
- **热门多元为主，偏好为辅**：以「在所选时间段里有多火」为主排序，偏好只做加减分（设置里可在「热门多元 ↔ 更懂我」之间调节）；没看过的内容分类会被优先推出来，不会连续投喂同一口味。
- **作者打散**：同一作者 20 条内最多出现一次，一次航程最多 2 条；每位创作者最多贡献 3 条候选，只取 TA 当时最火的作品。
- **互动**：点赞（双击视频）、收藏、评论（可展开楼中楼回复）、作者主页（可只看 TA 在该时间段的作品）、关注、复制链接。
- **人机验证交给你本人**：查看评论回复等操作有时会触发抖音的安全验证，应用会弹出「抖音安全验证」窗口让你亲自完成，完成后自动关闭并继续加载（客户端不会绕过或代做验证）。
- **学习**：观看时长（秒划算强烈负反馈、看完算强正反馈）、点赞、收藏、打开评论/主页、**不感兴趣（N）** 实时更新兴趣画像（作者 / 话题 / 抖音内容分类），每次切换视频都按最新偏好重排。
- **推荐理由**：每条视频下方注明为什么推荐给你（你关注的人 / 因为你爱看「音乐」/ 当年爆款 / 当年热梗：xx …）。
- **观看历史**、去除已看、请求频率控制、诊断日志。

快捷键：`↓/J` 下一条 · `↑/K` 上一条 · `空格` 播放/暂停 · `←/→` 快退/快进 5 秒 · `Z` 点赞 · `X` 评论 · `C` 收藏 · `F` 作者主页 · `N` 不感兴趣 · `M` 静音 · `⌘R` 随机穿越 · `⌘Y` 历史。

## 工作原理

抖音没有“按发布时间推荐”的接口，时光机是这样做的：

1. **网页桥接**（`Core/DouyinBridge.swift`）：在不可见的 WKWebView 中加载 douyin.com，所有接口请求都在页面上下文里用 `fetch` 发出，由抖音官方网页自己的安全 SDK 附加签名参数——客户端不实现任何签名或风控算法。
2. **创作者池**（`Engine/CreatorPool.swift`）：推荐流作者、你的关注、你的喜欢、当时热门话题页里的作者、相关推荐、视频中 @ 到的人都会进入池子。
3. **时代热点**（`Engine/EraKeywords.swift`）：按月整理的热点时间线。抖音搜索很容易被风控挂住，所以主力是**话题页**：从刷到的每一条视频里收集「话题名 → ID」存成本地话题目录，出发时直接翻当月热点话题的页面；扫描中发现的、至少 3 位不同作者都在用的话题也会被自动翻看（话题滚雪球）。
4. **时间跳转 + 按月分层采样**：作品列表接口的 `max_cursor` 是毫秒时间戳。多月时间段里，每次扫描挑一个“目前视频最少”的月份，从那个月月末往前翻，让结果均匀分布在整个时间段（而不是全挤在末尾几个月）。接口返回的 `time_list` 告诉我们每位创作者在哪些月份发过作品，据此跳过不相关的人。
5. **广度优先挑创作者（Thompson 采样）**：每位创作者“扫描一次能出片”的概率用 Beta 分布建模，再乘以 TA 作品的热度系数；偏好只轻微影响挑人，目标是多扫不同的、作品火的创作者，而不是反复翻那几个人。
6. **候选池 + 即时重排**：只提前排 3 条，其余留在候选池。每次切换视频都按「热度（时间段内排名 + 绝对互动量）+ 时代感 + 偏好（辅，可调）+ 新鲜分类加分」重新打分，并打散作者、内容大类和月份；连续两条都因偏好入队时，下一条让位给热门。

7. **并发、限速与风控**：3 个 worker 并发，普通接口默认每 0.4 秒一个请求；作品列表接口单独限速（≥0.9 秒、每小时最多 360 次），评论回复等敏感接口 ≥1.5 秒；后台不使用最容易触发验证的搜索接口。若作品列表被抖音临时限制（404 / 空内容 / 签名无效），自动冷却（30 秒起、最长 30 分钟，跨重启保存）并改用热门话题页继续找，冷却结束自动恢复。内容稀少的时间段（如 2018 年）会自动放宽作者间隔、加深缓冲。

> 未登录时抖音不提供创作者作品列表，只能从推荐流里筛选（基本只有近期视频）。登录后才能回到任意月份。

本地数据保存在 `~/Library/Application Support/DouyinTimeMachine/`。
